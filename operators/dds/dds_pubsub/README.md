# Generic DDS Publish and Subscribe Operators

This Python subproject provides two independent operators in the
`holohub.dds` namespace. Their behavior and integration instructions are
documented separately:

- [`ConnextDDSPublisherOp`](publisher/README.md)
- [`ConnextDDSSubscriberOp`](subscriber/README.md)

See the [RTI Connext DDS Module overview](../../../modules/holoscan-connext-dds/README.md)
for supported versions, container requirements, license setup, and runnable
examples.
